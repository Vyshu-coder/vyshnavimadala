# Developer Portfolio — Signal HUD

React 19 + Vite + Tailwind CSS 4 single-page developer portfolio with a dark, technical "Signal HUD" aesthetic.

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Features
- Signal HUD design language (dark ink, technical bone typography, vivid signal orange accent)
- Smooth scrolling with Lenis driven by GSAP ticker
- 3D centerpiece using Three.js
- Tailwind CSS 4 setup with `@theme` token definitions
- Contact form support powered by EmailJS
